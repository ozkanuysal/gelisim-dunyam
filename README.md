# Kişisel Gelişim Dünyam

Konu başlıklarına ayrılmış video ve kitap listesi. Açılışta 3D dünya küresi, içinde başlıklar, başlığın içinde tikli kaynaklar.

- Site: https://ozkanuysal.github.io/gelisim-dunyam/
- `veri.json`: başlıklar ve kaynaklar (`main` dalı)
- `tikler.json`: biten kaynaklar (`tikler` dalı; sayfa GitHub API ile okur ve yazar)

Tik atmak için sayfadaki **Anahtar gir** düğmesine, yalnızca bu repoda `Contents: Read and write` yetkisi olan bir fine-grained token girilir.
